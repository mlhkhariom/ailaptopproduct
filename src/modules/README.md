# Modules

Each module represents a business domain:

- `erp/` — Job cards, repair, services
- `crm/` — Leads, pipeline, automations
- `ecommerce/` — Products, orders, payments
- `cms/` — Blog, pages, media
- `hr/` — Staff, attendance, payroll

Modules can be enabled/disabled from Super Admin panel.
Each module's visibility is controlled by `mod_*` settings in DB.
